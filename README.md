# Hanaseru（話せる）

院長専用の語学トレーニング。**自分の言いたいことを、毎日ガンガン口に出す**ための最小アプリ（段階1 MVP）。

- 設計・記録の正本 → Obsidian `22_アプリ開発/Hanaseru 語学トレーニング/`（要件定義・詳細設計・実装計画・開発ログ）
- 思想 → 「成果 ＝(量 × 自分の文 × 正しい模倣 × 即時FB × 間隔反復) × 継続」。既製品（ELSA・Speak）は借りる。**自作は辞書・瞬発トレ・継続の3つだけ。**

## いま何ができるか（段階1 MVP）

1. 範囲を選ぶ（旅行・日常／診療英語／署名フレーズ／ぜんぶ）
2. **日本語が出る → その瞬間に英語で声に出す → タップで答え合わせ（音声で手本）→「言えた／まだ」**
3. 詰まった行は翌日また出る（間隔反復・Leitner）。連続日数が続く。
4. 進捗はこの端末に保存（サーバーなし・オフラインOK）

## 使い方（ローカル）

```bash
cd ~/Developer/hanaseru
python3 -m http.server 8080
# → ブラウザで http://localhost:8080 を開く（iPhoneは同一Wi-FiでMacのIP:8080）
```

`file://` で直接開いても動くが、Service Worker とホーム画面追加は http 経由を推奨。

## iPhone に置く

Safari で開く → 共有 → 「ホーム画面に追加」。全画面アプリとして毎日ワンタップで開ける。
（デプロイ先は Firebase Hosting を予定＝院長の既存インフラ）

## 辞書を育てる

`data.js` の `HANASERU_CARDS` に `{ id, domain, ja, en }` を足す。
元素材 → 院長の Notion `Medical English` DB＋Vault の辞書（20_診療英語 / 21_旅行日常）。
