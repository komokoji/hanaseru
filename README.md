# Hanaseru（話せる）

院長専用の語学トレーニング。**自分の言いたいことを、毎日ガンガン口に出す**ための個人用アプリ。

- 設計・記録の正本 → Obsidian `22_アプリ開発/Hanaseru 語学トレーニング/`（要件定義・詳細設計・実装計画・開発ログ）
- 思想 → 「成果 ＝(量 × 自分の文 × 正しい模倣 × 即時FB × 間隔反復) × 継続」。既製品（ELSA・Speak）は借りる。**自作は辞書・瞬発トレ・継続の3つだけ。**

## 3分練習（2026-10-01 改修）

ホームから、復習期限の文と自分が保存した文を中心に最大3文を練習する。

1. 言いたい内容を見て、まず今の英語で試す。練習前の手応えは任意で記録し、手本を聞く。
2. 意味を確認して音をまねる。必要なら録音し、手本と聞き比べる。
3. 日本語だけを見て、自力で英語を言う。
4. 相手・内容を変える、理由を足す、または同じ意味を言い換える。
5. 自己評価で次の復習日を決める。最後に、その表現を使うAI会話へ進める。

3分は所要時間の目安。録音や言い換えに時間がかかるときは、1文だけでもよい。
途中の位置はこの端末に保存。復習の成績・保存文・メモはログイン時に既存のクラウド同期を利用する。
同じ日の反復だけで復習間隔を伸ばさない。「まだ」は翌日へ戻し、同期でも新しい評価を優先する。

「今日つまずいたこと」には場面・つまずき・言いたかった内容を残す。
メモの「英語にする」→ 英訳を確認 →「この英文を保存して練習する」で練習につながる。
AIにはログインとネット接続が必要。保存済み教材の練習は、初回読み込み後はオフラインでも使える。
教材一覧・従来のカード・聞き取り・AI会話・1分で語るは、ホームの「教材を選ぶ・AIと会話する」にある。

録音はブラウザのメモリ内のみで扱い、送信も永続保存もしない。ステップ移動・中断・非表示で破棄する。
録音には HTTPS または localhost、MediaRecorder とマイク許可が必要。非対応・拒否時も口頭練習は継続できる。
手本は端末の合成音声。人による音声添削や発音の自動採点は未実装。

## 続けやすい分類と、休んだあとの再開

場面（診療／旅行・日常／自分の考え）と状態を別々に扱う。
「自分のことば帳」は、未英訳メモ／これから／練習中／実際に使えた／今は休む、の5つ。
既存教材すべてを未消化の課題にせず、自分の保存文と、見た・練習した・「あとで練習」に選んだ文を載せる。
実際に使えた記録は本人が付ける。暗唱の成功と区別し、復習の箱を自動で進めない。取り消しもできる。
「今は休む」にした文は3分練習の自動選択から外す。データは消さず、必要なとき戻せる。

院長の挫折理由は「忙しくて間が空き、再開しづらくなった」（今回の回答）。
そのため、3日以上空いたときは主ボタンを「1文から再開」に切り替え、練習したことのある短い文を優先。
忙しい日の1文コースは、聞く→まねる→見ずに言う、の3ステップで終わる。普段の3文コースも1文終えたところで終了できる。
継続の条件（院長の希望）：1日に一度、何か一つ取り組めば達成。セッション完了は不要。
手本を聞く、英文を表示する、練習前の発話を記録する、録音を始める、メモ・フレーズを保存する、AIに返答する等で記録する。
起動・ホームへの移動だけでは自動加算しない。同じ日は1回だけ。覚えたかの評価（復習の箱）には影響させない。
全画面共通の上部に「✓ 今日も取り組めました！」と連続日数、直近7日の取り組み日数を表示。
昨日まで続いている場合は今日の取り組み前にも連続日数を維持し、取り組んだ時点で1日加算。休んだあとの記録も消さない。
端末間で日付の和集合を取り、異なる端末で取り組んだ日を合わせて継続日数を計算。既存の連続日数も移行する。
新しい履歴は非連続でも端末間で統合。改修以前の履歴は復元できないため、既存の最終完了日だけを表示に引き継ぐ。
日替わりの言い換え・理由・確認質問で、同じ表現を違う使い方で練習する。

追加で分かった背景は「言いたいことと違う教材から始まり、本当に話せるようになるか疑問で、道が遠く感じられた」。
標準の自動出題は、自分の保存文と自分が選んだ・触れた文だけに限定。候補が尽きても、未選択の一般教材を勝手に足さない。
場面別を自分で選んだ場合は、その場面の教材から選ぶ。ホームに次の練習内容を日本語で表示し、目的を先に見せる。
練習前の手応え（任意）と練習後の自己評価を並べる。短期の自己評価を実会話能力の証明とは扱わず、AI会話や実使用の記録につなぐ。

生活の合図（昼食後など）に小さな練習を結びつける設計は、[習慣形成に関するレビュー](https://discovery.ucl.ac.uk/id/eprint/10144814/)を参考にした。
英語学習の継続効果を本アプリで実証したわけではなく、使用感と再開状況を見て調整する。

## 学習設計の根拠と限界

先生の課題に合わせ、音の模倣に「自力で取り出す」「新しい場面で使う」をつなげた設計。
特定の学習法が個人にとって最短になるとは断定しない。

- [シャドテン公式FAQ](https://shadoten.com/faq.html)：主な目的はリスニング力向上。音声添削を伴う反復を参考にした。本アプリの録音聞き比べは専門家の添削と同等ではない。
- [Lambert et al., Task repetition and second language speech processing](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/abs/task-repetition-and-second-language-speech-processing/0EA95A4C7D9E90CD2AB30043F84A4635)：日本人学習者の同一発話課題の反復と直後の流暢さ改善を報告。
- [The effects of distributed practice on second language fluency development](https://www.cambridge.org/core/journals/studies-in-second-language-acquisition/article/effects-of-distributed-practice-on-second-language-fluency-development/4F6787916C198376CAD222934D3B37E4)：間隔を空けた発話練習と流暢さの転移を検討。今回の3文・復習日程そのものが最適だと実証されたわけではない。
- [CEFR spoken language descriptors](https://www.coe.int/en/web/common-european-framework-reference-languages/table-3-cefr-3.3-common-reference-levels-qualitative-aspects-of-spoken-language-use)：B2は表現の幅・正確さ・流暢さ・やりとり・一貫性を含む。カードの習得数や3つの練習指標だけではB2認定はできない。

実践案：すきま時間に3分練習、時間がある日にAIと数往復。週に一度は未練習の質問で理由・言い換え・聞き返しを試す。定期的に実際の会話相手や指導者にも評価してもらい、次の弱点を決める。

